# launch

Launch a R Shiny-based applet for model diagnostics.

## Usage

``` r
launch(data = NULL, ...)
```

## Arguments

- data:

  A \`data.frame\` to use in modeling.

- ...:

  Currently ignored. For extendability.

## Value

None. Launches a \`shiny\` applet for point-and-click based model
diagnostics

## Examples

``` r
if (FALSE) { # \dontrun{
launch()
} # }
```
